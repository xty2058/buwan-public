## 启动

需要 Python 3.9+。运行时全部使用 Python 标准库和原生 HTML/CSS/JavaScript，没有 pip/npm 依赖；Node 仅用于 JavaScript 语法检查。已创建独立 `.venv/`，不向系统环境安装包。

1. 首次可双击 `初始化开发环境.command`，创建虚拟环境并执行数据库迁移/角色初始化。重复执行不重置已有数据。
2. 双击 `启动开发环境.command`，保持终端运行。
3. 打开 [http://127.0.0.1:8840](http://127.0.0.1:8840)，注册自己的本地测试账号。没有预置共享密码。
4. 结束时在运行终端按 Ctrl+C。

也可在本目录执行：

```sh
python3 -m venv --without-pip .venv
.venv/bin/python3 -B scripts/init_db.py
.venv/bin/python3 -B -m backend.server
```

配置在 `.env.example`。需要调整时复制为本目录 `.env`；环境变量优先。修改端口时同时修改 `APP_PORT` 和 `APP_ORIGIN`。默认会话有效期为 168 小时，可配置 1—720 小时。默认只监听本机，不开放局域网；API 严格校验 Host 和写入请求的 Origin，请使用配置中的完整地址。

当前是 HTTP 本机开发服务；生产部署须换为适合生产的服务托管方式并接 HTTPS，配置 Secure Cookie 等部署条件。Python 的 `http.server` 官方明确不建议直接用于生产：[官方安全说明](https://docs.python.org/3/library/http.server.html#security-considerations)。本轮未部署上线、未接短信/邮箱/第三方登录，也未提供密码找回。

## 目录与数据

| 路径 | 用途 |
| --- | --- |
| `frontend/` | 浏览器前端，不引用可点击原型的模拟数据或账户逻辑 |
| `backend/config.py` | 本地配置与环境读取 |
| `backend/db.py`、`migrations/` | SQLite 连接、事务和校验和迁移 |
| `backend/auth.py` | 密码、登录凭证、CSRF、限流 |
| `backend/service.py` | 角色版本、会话、消息与归属校验 |
| `backend/api.py`、`server.py` | JSON API、静态资源白名单、开发 HTTP 服务 |
| `backend/logs.py` | 结构化错误与请求日志 |
| `backend/seed_characters.json` | 林屿、陆野、沈砚 v1 的公开资料与私有规则快照 |
| `scripts/` | 初始化与本地角色新版本发布工具 |
| `tests/test_foundation.py` | 自动测试，使用临时数据库，不改真实开发记录 |
| `docs/` | 数据与接口设计、验证记录、验收截图 |
| `runtime/app.sqlite3` | 自动创建的真实开发数据库，已排除版本管理 |
| `runtime/logs/app.jsonl` | 运行日志，2 MB 轮转，保留 3 个备份，已排除版本管理 |
| `.venv/` | 独立开发解释器环境，已排除版本管理 |

退出登录会撤销当前凭证并清理页面内私人内容、草稿；不会删除数据库中的已保存记录。数据库文件丢失后没有远端副本。请保留账号凭证，当前不能通过昵称找回账号。

前端草稿与尚未确定结果的请求目前保留在页面内存；同一页面内返回可重试原请求。刷新、关闭页面后的完整草稿/生成任务恢复属于步骤 6，本轮不承诺已完成。会话使用标识可刷新复用、显式关闭，退出登录会关闭当前凭证下的使用记录；真实关闭浏览器与跨设备临时关系边界仍须步骤 8 完整接入。

## 角色版本

首次初始化读取种子 JSON，已有 v1 不会在重启时被覆盖。修改种子文件不等于修改已发布数据。需更新角色时，用单个角色定义 JSON 提高 `version`，通过本地工具新增版本：

```sh
.venv/bin/python3 -B scripts/publish_character.py /绝对路径/角色新版定义.json
```

结构参照 `backend/seed_characters.json` 中的一项，公开和私有字段分开。该工具无对外管理 API；新版本只影响新账号首次创建的新会话，已有会话保留原版本。不要编辑已经应用的 SQL 迁移，后续变更追加新的迁移文件。
