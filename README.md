# 不晚 · AI 情感陪伴

手机优先的 AI 陪伴产品。与独立书店店主林屿聊天，让确认过的记忆和共同经历延续下去，关系的节奏由你决定。

这是当前产品的可运行发行版，版本信息见 [VERSION](VERSION)。只包含应用源码、当前角色与提示词、必要界面资源和部署工具；不包含作品集、研究报告、设计探索或内部评测系统。

## 产品能力

- 流式聊天、停止、重试、重新生成候选、会话恢复。
- 长期记忆确认、纠正、删除、分类、来源追溯与人物画像。
- 关系档案、约定、时间感知、共读和数据导出。
- 同一会话中的剧情支线与切换。
- 「帮我想想」提供回复选项，选择后只填输入框，由你发送。
- 回访时的克制主动消息，可关闭，有静默时段与冷却限制。
- 可选角色语音播放；语音输入接口已接入，默认未启用。
- 静玻璃界面，保留少量暮光。当前开放林屿，其他角色保留为待开放。

## 本机启动

安装 Python 3.10 或更高版本，无需 pip 安装依赖。在仓库根目录运行：

```sh
python3 start.py
```

打开 http://127.0.0.1:8840 。不配置模型时可浏览界面、注册账号，真实回复不可用；本地数据保存在应用的 `runtime/`，不会上传到本仓库。

要使用真实回复，在自己的终端设置环境变量后生成配置（不要把真实密钥写进 Git）：

```sh
export DEEPSEEK_API_KEY='填你自己的密钥'
export DASHSCOPE_API_KEY='填你自己的密钥'
# 可选：export MINIMAX_API_KEY='填你自己的密钥'
python3 'MVP1.0/步骤4-前后端与数据基础/scripts/deploy_config.py'
python3 start.py
```

模型调用由你自己的服务商账号计费。默认回复模型为 DeepSeek Flash、林屿提示词 v1.8；记忆和向量使用通义千问服务。公开版仅附当前 v1.8 提示词，不支持选择历史版本。修改配置后需重启服务。

## 服务器部署

需要 Docker、域名和服务器。详见 [部署说明](deploy/README.md)。

```sh
cp deploy/.env.example deploy/.env
# 编辑 deploy/.env，填写域名与自己的密钥
docker compose -f deploy/docker-compose.yml up -d --build
docker compose -f deploy/docker-compose.yml exec app python3 scripts/invite.py create --label 朋友 --uses 1
```

默认邀请制注册、只开放林屿，Caddy 提供 HTTPS。源码静态托管不能运行 Python 后端；本仓库不提供 GitHub Pages 在线应用。

## 当前边界

- 分支不是完全独立存档：分叉前记忆的修改、删除全线共享，共读活动不分线；旧会话缺少历史关系检查点，早期分叉无法精确还原当时关系。
- 主动消息仅在用户返回聊天时触发，无系统推送；默认开启，可在关系页关闭。
- 语音输入默认关闭，真实识别与 iPhone / Android 麦克风体验尚未完成验证。语音播放需单独配置 MiniMax。
- Docker 默认每人每天 60 次、全站 1500 次回复请求，北京时间零点恢复；失败不计，停止仍计。它是防滥用次数，不是付费额度；辅助模型调用另计服务商费用，本地默认无每日次数上限。
- 暂无会员、支付、积分、实时语音通话。工程集成不等于全部真实设备和长期体验验收完成。
- API Key、用户账号、聊天、数据库不随源码提供。请自行配置、备份自己的数据。
