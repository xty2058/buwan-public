#overview

产品与用户

不晚是一款 AI 角色陪伴产品。设计主线优先服务恋爱向重度玩家，同时不排斥慢热的日常陪伴用户；角色创作者暂缓，只在规范里预留扩展位。

A · 核心

恋爱向重度玩家

成年女性，学生或年轻白领。把角色当“可互动的小说”，长期绑定一个角色，重剧情、重分支；碎片时间高频使用，小额月付。

B · 次要

慢热日常陪伴

要的是“记得我、每天聊几句”。追求平淡的幸福感，有情绪需要时打开。

C · 暂缓

角色创作者

本期不设计。预留：角色卡作者区、--bw-portrait-n 立绘扩展。

#principles

品牌原则 P0–P6

每条原则都能从场景追溯到 Token。编号是检索锚点：在代码里搜 P3 能找到所有服务“记得对”的 Token、组件和页面（@principle 注释与 data-principle 属性）。完整推导表见 基础 · 推导表。

P0 · immersion

角色在前，界面让位

洞察挑剔没耐心；最烦沉浸被打断、聊天里插广告（S1 S2）
承诺3 秒判断合不合拍；聊天区没有任何商业内容
原则立绘和台词是主角，界面是玻璃，看得见但不抢
决策暮光环境光 + 半透明玻璃；聊天流禁止推广组件
Token / 组件--bw-glass-* --bw-aurora Spotlight Starter
P1 · same-person

同一个人：人设恒定

洞察首聊太像 AI；换模型像换人（S1 S3）
承诺第一句就像这个人；换了引擎还是这个人
原则角色的视觉身份永远不变，变化必须被说明
决策开场预览角色原话；模型更新给出人设锚点清单
Token / 组件--bw-portrait-n OpeningPanel Checklist
P2 · steady

稳：反馈及时，节奏匀速

洞察回复截断、重复、生成慢卡顿（S2）
承诺有回应就显示；出错说清楚并且不扣
原则动效慢一拍、不回弹；不伪造延迟
决策呼吸式输入指示、流式光标、气泡内续写/重写
Token / 组件--bw-dur-* --bw-ease-out Typing Retry
P3 · remember-right

记得对：记忆可见、可改

洞察最高频痛点：忘了前文和重要剧情；记错改不了（S3 S4）
承诺它记得什么，你看得见；改了马上生效
原则记忆有专属的烛金色，只给记忆用
决策“想起了”标签、记忆列表、原来 → 改为 的纠正面板
Token / 组件--bw-color-memory-* MemoryChip Correction
P4 · you-decide

由你决定：选择等权，不代答

洞察AI 替用户答应、推进；用新会话代替分支（S2 S4）
承诺你的话只由你说；在这里分岔，原线还在
原则接受和拒绝同样好点；用户声部视觉独占
决策等宽选择组；用户气泡实底；任意消息可分岔
Token / 组件--bw-color-user-* ChoiceGroup Branch Stage
P5 · continue

接得上：从上次那一页开始

洞察隔天回来关系断了；存档丢、角色下架（S3）
承诺回来第一眼就知道聊到哪；存档一直在
原则“一根线”贯穿共同经历
决策回顾卡、未完成约定、时间线、存档状态常驻
Token / 组件--bw-gradient-memory Recap Timeline Continuity
P6 · rules-first

规则先行：先讲怎么扣，再讲多少钱

洞察规则看不懂、失败照扣、怕跑路涨价（S5）
承诺一句话讲清怎么扣；每一笔都能查
原则付费只用系统声部，绝不借角色口吻催付
决策规则清单在价格之上；明细表标“未扣”；退订同屏
Token / 组件--bw-glass-solid --bw-text-hero Checklist Plan Table

#keywords

关键词与反关键词

“不晚”取“天将黑未黑、一切还来得及”。视觉方向“暮光玻璃”：未来感来自玻璃与环境光，温暖来自杏色到玫瑰的暮光，高级来自颗粒质感和克制的留白。

是

  • 暮光：环境光而不是色块，像傍晚的天
  • 玻璃：层级靠材质，看得见角色也看得见界面
  • 烛金：被记住的东西会微微发亮
  • 一根线：共同经历连成一条线，接得上
  • 成年人的温度：亲密但克制
  • 明白：规则写在价格前面

不是

  • 霓虹赛博：冷蓝紫发光会让人联想到“不稳定的 AI 玩具”
  • 糖果少女心：幼态化让成年用户不适
  • 游戏 HUD / 抽卡金光：把关系变成交易
  • 黑盒：“AI 自己知道”，用户看不见记忆
  • 倒计时、红点轰炸：“怕被坑”的直接来源
  • 玻璃叠玻璃：好看但读不清；最多两层
